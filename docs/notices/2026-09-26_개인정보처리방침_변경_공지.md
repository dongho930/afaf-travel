# [안내] 개인정보처리방침 변경 안내 (2026년 10월 3일 시행)

안녕하세요, 경기포올입니다.

더 나은 여행 추천을 위해 수집·보관하는 정보가 바뀌어 개인정보처리방침을 아래와 같이 변경합니다.

## 시행일

2026년 10월 3일 (이전 방침: 2026년 9월 17일 시행)

## 주요 변경 내용

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 수집하는 정보 (1조) | - | **추천 품질 개선 기록**을 새로 수집합니다. AI 추천 요청 문장, 선택한 이동 유형·지역·방문 예정일, 추천받은 장소와 그중 선택한 장소, 로그인한 경우 회원 식별번호가 해당됩니다. 추천이 실제로 도움이 되었는지 분석하는 데만 사용합니다. |
| 보유 기간 (3조) | - | 추천 품질 개선 기록은 **수집일로부터 90일** 동안 보관한 뒤 자동으로 파기합니다. |
| 음성 입력 (2조) | 기기의 음성인식 기능이 글자로 바꾼다고만 안내 | 음성이 기기·브라우저의 음성인식 서비스(Android는 Google, iOS는 Apple, 웹은 이용 중인 브라우저)로 전송될 수 있고, 경기포올 서버로는 바뀐 글자만 전송된다는 점을 밝혔습니다. |
| 자동 수집 장치 (5조 신설) | - | 쿠키를 사용하지 않는다는 점, 기기·브라우저 저장소에 저장하는 정보(로그인 상태, 선택한 이동 유형, 화면 테마, 사용법 안내 확인 여부, 최근 만든 코스)와 지우는 방법을 안내합니다. |
| 국외 이전 항목 (6조) | AI 코스 요청 문장, 이동 유형·지역 | 방문 예정일을 추가했습니다 (AI 코스 생성을 위해 Groq, Inc.(미국)로 전송). |
| 조항 번호 | 1~9조 | 5조가 새로 생겨 기존 5~9조가 6~10조가 됩니다. |
